# Análisis de sentimiento de acciones con IA

**En una frase:** clasifica el sentimiento (positivo/negativo) de textos sobre acciones bursátiles con técnicas de procesamiento de lenguaje natural.

## Contenido
- `Stocks Sentiment Analysis Using AI.ipynb` — limpieza de texto, entrenamiento y evaluación del modelo.
- `stock_sentiment.csv.xlsx` — conjunto de datos.

## Tecnologías
Python · Jupyter · NLP
